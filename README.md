# Car Window Shader

VRChat向け車の窓シェーダーです。

## VCCでのインストール方法

1. [VCC（VRChat Creator Companion）](https://vrchat.com/home/download) を開く
2. `Settings` → `Packages` → `Add Repository` をクリック
3. 以下のURLを入力して `Add` をクリック：
   ```
   https://sizimityper.github.io/vpm/index.json
   ```
4. プロジェクトを開いて `Manage Project` からパッケージを追加
